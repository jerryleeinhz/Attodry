# 光功率参考差分分析

本功能在只读分析层计算同一组照光数据相对于某个设定光功率的变化。已有的光照原始值、
运行内 dark 差分和独立 dark run 差分各自保留。功率参考差分不要求激光 OFF，
因此非零参考功率下的结果表示相对照光响应变化，不能解释为无光背景扣除。

## 1. 日常使用

打开 `notebooks/unified_plotting.ipynb`，或使用相同分析实现的组合扫描 Notebook，
选择需要的源文件和 run，再显式 Load。绘图卡片的 Response 增加两种模式：

| 界面选项 | 保存的 `photoresponse` | 参考选择 |
|---|---|---|
| Light − lowest-power light | `power_lowest` | 本组归档计划中最低的设定光功率 |
| Light − selected-power light | `power_selected` | 明确填写的参考设定功率 |

指定功率控件使用 μW；保存绘图设置时，`reference_power_w` 统一使用 W。
例如选择 6 μW，保存值为 `6e-6`。选择普通锁相 X/Y/R/Phase 作为纵轴，
Response 会转换为对应的功率参考差分通道；XY–Z 和多通道图使用同一规则。
横轴可使用设定功率，也可使用已保存的实测功率；参考选择始终以设定值为准。

例如同一外层访问有 1、6、15、25、40 μW 五个功率点，选择最低功率模式，
或指定 1 μW 后，结果都是其余点相对于 1 μW 的变化。选择 6 μW 则得到相对于
6 μW 的变化；小于参考功率的点仍可保留有符号的 ΔX、ΔY。

这两个选项对原始 light 做一次扣除，不再叠加运行内或独立 dark 扣除。保存／重新
加载绘图设置会保留 Response 和指定功率。仅使用已有归档，不修改采集 TOML。

Python 脚本也可直接调用同一实现：

```python
from attodry_control.combination_analysis import load_combination_rows
from attodry_control.optical_power_reference import subtract_power_reference

rows = load_combination_rows("archive.sqlite", run_id="your-completed-run")
relative = subtract_power_reference(rows, mode="power_lowest")
# 或明确以 6 μW 为参考；单位为 W：
relative = subtract_power_reference(rows, mode="power_selected", reference_power_w=6e-6)
```

读取入口沿用原默认合格 run／attempt 过滤。输出行的 `status.lockin.power_reference`
保存逐路结果；参考样本的原始 X/Y、实测功率、时间和量程也随目标行保存，即使图中隐藏
参考功率，导出仍能追溯扣除数值。返回的归档 `analysis_context` 是共享只读元数据，不应改写。

## 2. 参考点怎样匹配

每个参考池固定同一数据源、同一 run、非功率计划条件和外层轴访问身份。温度、
磁场、波片角度、波长／带宽、SMU 条件、激励、参考频率、谐波以及通道必须相符。
相同磁场或温度的往返访问通过归档计划索引区分，不能只按数值相同而合并。

只开放功率这个比较维度。经归档确认由功率反馈决定的起始电流／源控制值不作为
额外分组条件，否则五个调功种子会被误当成五种不可比较的实验。非反馈 direct
源模式和未知映射不会自动获得这个例外。量程规则名和灵敏度档位可以不同，
实际设置可比性仍须逐路检查。

最低功率来自本组归档扫描计划，不能根据锁相信号最小值、实测功率噪声或当前
绘图筛选后的剩余点选择。若计划最低点缺测、全被排除、通道不合格或身份含糊，
该组差分不可用，不会退而选用第二低功率。旧数据没有足够计划证据时，请尝试
明确指定功率；指定模式仍要求能证明参考与目标属于同一次可比较的外层访问。
无法证明时保留无效原因，不自动跨 run 寻找参考。

参考样本选择先应用手动排除，再建立参考池，之后才应用曲线范围、坐标切片等
绘图过滤。因此隐藏参考功率点并不取消它作为参考；手动排除某个参考样本则会
重新计算参考均值。源样本和排除记录始终保留在分析导出中。

## 3. 通道质量和不同量程

XX、XY、AUX 分别选择合格参考，一路无效不阻止另外两路。参考及目标必须有已接受
正式样本、有限复数读数、明确的本路质量和正式设置验证；过载／输入范围异常、
失锁、设置核验失败或证据缺失均不能生成合格差分。审计视图可展示原因，不能把
原始 rejected 或未知质量转成有效差分。

分点固定灵敏度允许不同：归档读数已经是 V，并保留双方实际确认量程。其他参考、
相位、输入模式、谐波、TC／滤波等影响复数可比性的设置仍须相符。仅有 TOML 目标
量程或规则名不能替代正式读回验证。不自动相位旋转、幅值归一化或校准未知增益。

## 4. 数值和误差含义

每路将参考功率中合格重复的复数读数平均：

\[
Z=X+iY,\qquad \overline Z_{\rm ref}=\frac1{n_{\rm ref}}\sum_j Z_{{\rm ref},j}
\]

对目标读数计算：

\[
\Delta Z=Z-\overline Z_{\rm ref},\quad
\Delta X=X-\overline X_{\rm ref},\quad
\Delta Y=Y-\overline Y_{\rm ref}
\]

差分幅值为 \(|\Delta Z|\)，差分相位由 `atan2(ΔY, ΔX)` 得到。它们不是
`R − Rref` 或两个原始相位的直接相减。零复数向量相位未定义。
汇总图中的 R／相位从重复样本的复数差分均值计算，而不是平均各个重复的 R／相位；
因此复数均值为零时，不能用非零的逐样本幅值平均数代替汇总幅值。

SD 描述目标重复读数扣除同一参考均值后的散布。SEM 描述均值估计的不确定度，
对不重叠的目标／参考样本，复平面协方差按下式合并：

\[
\Sigma_{\Delta\bar Z}=\frac{S_{\rm target}}{n_{\rm target}}+
\frac{S_{\rm ref}}{n_{\rm ref}}
\]

这里 `S` 是 X/Y 的样本协方差，包含交叉项。共享参考均值误差不能再除以目标
重复次数；多个功率点引用同一参考，其误差相关，导出用参考 ID 和协方差保留这个
关系。后续拟合若把各点当作独立误差，需自行处理这项相关性。

参考功率减自身时，单个参考样本减参考均值仍可能非零，但相同样本集合的均值
差严格为零。均值误差也须按共享样本抵消，不能当成两组独立数据相加。SD 仍反映
参考重复的散布，不能因均值为零而伪造零噪声。少于两个独立重复时，相关样本
方差／SEM 无法估计，显示为未知，不填零；精确自减的恒等关系单独标记。

幅值／相位误差采用复平面协方差的一阶传播；零幅值或缺失协方差时不伪造误差。
这些误差不包含未测的时间漂移或系统校准误差。记录参考与目标采集时间及间隔，
扣除一个参考点不证明时间漂移已经消除。

## 5. 导出和追溯

新的数值使用 `*_power_delta_*` 独立字段，与现有 dark 差分区分。导出同时保留
原始 light 值、逐路差分、参考模式及设定功率、实测功率统计、参考样本 ID／数量、
参考复数均值／协方差、目标与参考实际量程、采集时间／间隔、完整匹配条件、
手动排除记录和不可用原因。原始数据库和实验文件保持原字节。

功率参考模式的导出文件为：

- `selected_samples.csv`：实际进入本图的合格样本与功率参考差分；
- `analysis_audit_samples.csv`：分析审计样本，包括无效、手动排除和显示筛选状态及原因；
- `plotted_statistics.csv`：绘图所用统计值，R／相位由复数差分均值推导；
- `plot_manifest.json`：Response、参考功率、参考来源、匹配和误差处理等绘图设置与追溯信息。

参考组的单个样本减参考均值可以有散布；同一组参与样本的复数均值差仍为零。
审计 CSV 与绘图样本表用途不同，不要把其中的无效或排除行重新当作合格差分汇总。

遇到“没有差分”时，先查看导出的逐路原因：计划最低功率是否缺测、参考是否被
手动排除、是否有过载／设置证据缺失、外层访问是否能区分、指定功率是否属于
本组计划。不要通过合并往返分支或把未知质量改为 clean 来制造可用点。

## 6. 实现边界与验证

该功能只导入分析／绘图依赖，读取已保存记录，不创建仪器连接、不消费状态锁存、
不改变任何采集等待或调光过程。参考池按源／run／匹配条件建立索引，复用已计算的
参考统计；改变画布或横轴不重复读取数据库，也不逐行扫描全量候选。

相关离线测试覆盖最低／指定参考、计划缺口、往返访问、不同灵敏度、逐路过载、
正式设置证据、排除和绘图过滤顺序、共享误差、自减、保存设置与导出，并回归
原 light–dark 路径。测试结果记录在本轮交接／阶段条目中。此文描述本地分析功能，
不表示已经 push、部署 LK_setup 或进行实机验收。
