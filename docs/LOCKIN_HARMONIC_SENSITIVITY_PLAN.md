# 分谐波 Sensitivity：先固定量程验收，再增加变换量程

日期：2026-09-28。状态：F0/F1/A1 实现与离线验收完成；真实仪器验收未进行。

## 1. 本次约定与阶段边界

操作者要求：先验证固定量程，成功后由 Codex 自行继续增加变换量程功能，
完成后统一报告；先修改计划并 push 到 origin。拟合模型在 side chat 继续讨论。

实施顺序为：现有固定量程回归 → 各谐波固定档位 → 各谐波有界自动变换量程。
第一步中的“固定”表示每个角色、每个谐波的目标档位由用户预先指定，不随
该点读数自动调整；不同谐波之间仍会按预设切换 SENS/RMOD。后续“变换量程”
在这些独立谐波设置上增加按信号调整的 bounded_auto 策略。

前阶段离线验收通过后，自动推进后续离线实现，不为普通实现选择重复请求确认。
若发现失败，先修复并重跑相关测试，不能跳过关卡或把部分通过写成完成。
真实仪器连接、状态锁存消费、设置写入和站点部署属于单独的实验阶段；
离线测试通过不等于真实固定量程已经验收。未来真实验收同样先固定、后自动。

本计划提交不修改 H1/H2 拟合、校准公式、绘图控件或 notebook 的分析逻辑。
这些工作由 side chat 讨论，避免在两处同时修改同一分析功能。

## 2. 目标接口与日常用法

沿用 ignored `hardware.local.toml` 作为日常参数入口，按 `lockin_xx` / `lockin_xy`
及 h1/h2/h3 设置。先提供可选的固定档覆盖，缺省时继承原有角色默认配置。
以下固定档接口已实现并通过离线测试：

```toml
[lockin_xy.harmonic_settings.h1]
sensitivity_mode = "fixed"
sensitivity_full_scale_v = 0.1
reserve_mode = "low_noise"

[lockin_xy.harmonic_settings.h2]
sensitivity_mode = "fixed"
sensitivity_full_scale_v = 0.002
reserve_mode = "normal"
```

XX 和 h3 使用相同结构。未显式覆盖的阶数继承角色基础设置；明确区分
“未配置”和非法空值。Sensitivity 使用 V 单位，配置界面可显示 mV/µV；
Reserve 使用已有枚举，不以仪器编号区分角色，不自动调整参考源或相位。

XY h1=100 mV/Low Noise、h2=2 mV/Normal 是前文数据分析给出的候选设置，
不是对未来样品或全部激励范围的保证。本计划不把它们写成全项目默认值。
固定阶段已将 XY 2 mV 和 100 mV 加入明确白名单并测试；它们是候选档位，
不改变默认设置，不绕过白名单，也不扩大激励输出上限。
允许哪些自动量程阶梯在自动阶段单独明确定义和验证，不由固定档列表隐式推导。

### 冲突处理

- 未配置分谐波设置时，旧 fixed/bounded_auto/分段覆盖的行为保持兼容。
- 固定阶段先支持角色基础模式为 fixed 的分谐波固定覆盖。
- 同一角色同时启用分谐波覆盖与显式扫描分段量程覆盖，预检拒绝歧义。
- 固定阶段同一角色的 bounded_auto 与分谐波覆盖不能混用；另一角色可保持
  原有配置，其行为必须有回归覆盖。
- 自动阶段解除经过验证的组合限制，使用统一的 `(role, harmonic)` 配置解析，
  不让旧的每角色自动量程状态与新的谐波状态同时控制一个 SENS。

## 3. 阶段 F0：固定量程基线回归

目标：在增加新的采集行为前，确认现有固定量程、谐波切换、记录与 cleanup 路径。

1. 运行相关配置、SR830 fake-VISA、独立 sweep 和组合采集回归。
2. 明确当前三类 sweep 的 SENS/RMOD 写入、读回和恢复路径；复用已有驱动接口。
3. 核对两段等待的时序，记录总等待，避免把单段 5 s 错报为总等待。
4. 保存测试结果；若发现当前分支基线失败，先确认并修复本功能依赖的缺陷。

通过条件：相关测试通过，现有固定量程的命令顺序和异常恢复已被测试覆盖。
本阶段不以历史原始记录无 overload 或误差棒小作为软件/硬件验收的替代。

## 4. 阶段 F1：各谐波固定档位

### 实现

- 严格解析可选分谐波配置，校验合法谐波、离散量程、Reserve 和角色白名单。
- 在统一 sweep 采样路径中解析当前 `(role, harmonic)` 的目标配置，支持
  frequency、excitation 和 frequency_excitation 三种独立扫描。
- 组合采集通过现有 Lock-in 采样适配层复用同一逻辑，不复制切换代码。
- 只写需要改变的设置；正式样本必须对应确认过的谐波、量程和 Reserve。
- 进入较小 H2 档前先保持能容纳过渡信号的档位，切换谐波并完成过渡等待/
  状态检查，再应用目标 SENS/RMOD，重新等待并核对读回。返回大信号 H1 前
  先恢复适当的大量程。具体命令顺序由 fake-VISA 断言验证。
- 所有被实际切换和读取的伴随角色也必须使用合法配置，不能仅验证正式选择的角色。
- 每次量程/Reserve 变化后核对实际时间常数；读回不一致、通信异常及正式窗口
  输入/储备/滤波过载按现有规则拒绝。维持项目当前对各状态位的既定含义。
- 不把固定等待或状态位清除等同于样品达到稳态，不改变 H2 数据或误差棒来
  隐藏暂态。

### 记录与 cleanup

正式样本关联实际 `(role, harmonic, sensitivity_full_scale_v, reserve_mode)`；
过渡事件记录前后设置、写入/读回、时间戳、等待、状态与失败原因。
记录格式兼容旧 JSON；旧记录缺少设置时标记未知，不以当前 TOML 回填。
配置快照/measurement profile 及其哈希必须包含新设置。

正常结束和异常/Ctrl+C 沿用当前最小激励与 h1 恢复协议。切回 h1 前处理量程
顺序；最后恢复并验证既定 TOML 基线 SENS/RMOD，不能把最后一次 H2 档当作基线。
恢复失败保留最后确认读回并明确要求人工核查，不能报告已恢复。

### F1 验收关卡

必须覆盖：

1. 旧配置、默认继承、XX/XY 独立覆盖、h1/h2/h3 和非法/未知配置；
2. 实际 SENS/RMOD 写入与查询、无变化时不重复写入；
3. H1→H2→H1 命令顺序、过渡等待及正式采样前设置确认；
4. 写入失败、错误读回、状态异常、通信丢失和 Ctrl+C 后的拒绝/恢复；
5. 三类 sweep、伴随通道及组合适配层复用；
6. 新旧记录/配置快照兼容及实际设置可追溯；
7. 与分段覆盖及 bounded_auto 冲突时在硬件打开前拒绝。

F1 全部通过后，记录明确的测试清单和结果，自行继续 A1；不再为开始 A1
重复询问操作者。F1 失败则修复，不提前启动依赖它的自动量程功能。

## 5. 阶段 A1：各谐波有界自动变换量程

目标：在已经验证的分谐波设置与切换流程上，按 `(role, harmonic)` 各自维护
bounded_auto 状态、量程阶梯、上下限和缩窄计数。可以 H1 fixed、H2 bounded_auto，
也可以两者均 fixed；自动策略始终需要在配置中明确启用。

- 复用现有有界量程策略和已定义的探测/正式窗口分离，不调用无界 Auto Gain。
- 自动阶段的每个谐波使用明确的允许阶梯、起始量程、占用率和稳定样本数，
  不能把 H1 的历史占用率/量程直接当作 H2 的判断依据。
- 缩小 H2 档不能只看 H2 的 R。输入中 H1 仍存在，必须考虑该档 Reserve 和
  输入/储备/滤波状态；沿用有界探测失败的处理，不能将过载探测当成正式样本。
- 各谐波切换和自动调档共享 F1 的时序、读回、等待、记录与恢复逻辑。
- 范围变化、回退和拒绝原因全部归档；不因调档而修改原始电压、删除 rejected
  尝试或重定义旧数据的单位。

通过条件：F1 回归继续通过，新增 fake 测试证明自动调档有界、无跨谐波状态泄漏、
不因小 H2 忽略大的输入背景、无反复缩放振荡、不会越过白名单/阶梯，且固定/自动
混合设置、过载、通信故障、最高/最低档和 cleanup 均受验证。

## 9. 操作者要求的调度修正与过载诊断（2026-09-28；离线完成）

F1/A1 最初继承了“双台同步切换、仅按选择过滤正式数据”的旧调度。现已修正：
每台只切换到自己选择的谐波，XX h1 + XY h2 在各点间保持各自检测状态；
多谐波循环仅作用于选择了多个阶数的角色。伴随安全检查读取实际谐波，
不得把另一台的阶数套在该读数上。只有超出检测频率范围的停靠和最终 cleanup
需要恢复 h1；固定量程持续输入过载还有下面这项明确的中止专用例外。

操作者要求：固定量程的 input/reserve overload 经复查仍存在时，中止前将
过载角色切回 h1 保存一次诊断。该步骤保持故障时的 SENS/RMOD/激励，保留
原始样本、h1 样本和实际设置；不自动改量程，不接受诊断数据，不继续扫描。
诊断通信失败或 Ctrl+C 不能掩盖原始错误、阻止 cleanup。自动量程以及清除的
瞬态不触发额外 h1 诊断，纯 preflight 失败仍不写仪器。
