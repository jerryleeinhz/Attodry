## 三类独立判据与配置

| 表／字段 | 单位与用途 | 缺省兼容行为 |
|---|---|---|
| power_feedback.tuning_tolerance_fraction | 目标的分数，调光中心范围 | 省略时沿用原 target_tolerance；旧配置含义不变 |
| target_tolerance_fraction / target_tolerance_w | 目标的分数／W，正式验收，二选一 | 原有规则不变 |
| window.max_peak_to_peak_w | W，峰峰值绝对上限 | 原有规则不变 |
| window.max_peak_to_peak_fraction | 目标的分数，低功率相对峰峰值限制 | 省略时仅使用原绝对上限 |
| window.noise_floor_w | W，相对峰峰值判据的实测噪声底 | 0；没有证据时不猜测噪声底 |
| window.max_drift_fraction_per_s | 目标的分数/s，线性拟合漂移斜率绝对上限 | 省略时保留原无趋势判据 |
| max_retries | 追加次数，dark-first 扫描 | 0，保持原不重试行为 |
| point_timeout_s | s，亮功率轴一次 visit 的总预算，含全部内层电学坐标 | 省略时无新增总预算；启用重试必须填写 |

峰峰值有效上限为 `min(max_peak_to_peak_w,
max(noise_floor_w, target_power_w * max_peak_to_peak_fraction))`。
趋势用原始 PM 样本及实际单调时钟做最小二乘斜率，不增加平均次数来隐藏漂移。
时间覆盖、最少样本数、峰峰值、趋势及调光范围必须同时满足，再持续 hold_s。
采样间隙超过窗口长度时丢弃稳定证明，保留原始读数。

本轮示例显式使用调光 ±5%、验收 ±10%、5 s 窗口、2 s hold、
相对峰峰值 5%、漂移 0.2% 目标/s、最多追加 2 次、600 s 总预算。
这些来自操作员建议及待验证的质量策略，**不是仪器指标或已测噪声**。
noise_floor_w=0，不能自动提高。低功率不能满足时应报告失败并测量实际噪声，
不能自动扩大任何容差。硬件示例仍需复用已确认站点身份、接线与物理上限。

旧配置的新增默认字段从 snapshot 中省略，以保留已有计划散列和断点校验。
启用新的非缺省策略会改变 snapshot；不允许将新配置伪装成历史 unchanged resume。

## 调光与扫描流程

1. 温度／磁场仅在相应外层 visit 设置和完整判稳；内层记录实际值并检查异常。
2. 激光关闭时设置波长、带宽和 PM 波长校正。每轮先采一个暗点；偏置／栅极
   等内层坐标各自匹配本轮暗态。回访／重复／恢复仍需新的外层判稳及暗态。
3. 亮点以本轮上一有效功率点的执行器设定起步，不复用稳定证明。
   换波长或带宽后清除响应历史。
4. 在已有执行器边界和单步上限内粗调；偏差低于目标 25% 时主动缩小步长，
   方向反转继续缩步，NKT 下限为 0.1 个百分点。可用同波长、已通过稳定检查的
   电流—实测功率对估计局部斜率，限幅后再由新鲜 PM 读数确认；不假定绝对比例。
5. 每次实际调整都先关光、调整并读回、再开光，重新建立完整窗口及 hold 证据。
6. 光稳定后完整核对相关电学设置。核对后再读新鲜 PM，要求仍在调光中心范围且
   没有越过波动／趋势／硬件界限，然后才 prepare 激励／采集。
   2400 在完整配置且输出仍关闭时执行这一屏障，回调的普通光学拒绝不会被
   错误地标成仪器通信故障；所有真正设备错误仍使设备会话失效。
7. 后续内层电学坐标改变前再次检查功率；正式读取前后的 PM 与动态保护检查保留。
   正式窗口内不调光。每次新鲜 2182A READ 仍有完整前后设置核对。
8. 保存实际 PM 功率、目标、偏差、峰峰值、趋势、时间、有效性、暗态引用及年龄。
   无激励 2182A 路径只用 6221 转发，持续确认输出关闭／电流设定零，不创建激励源。

## 有限恢复和原始数据

只有 `PowerDeviation` 属于普通可恢复光学偏差。采集前的偏离返回调光；正式
窗口中的偏离使整个窗口无效，不能将先读到的电压拼入下一次尝试。

`conditions[].power_attempts` 保存次数、失败原因、起止时刻、失败完整/部分窗口
和清理结果；成功尝试只引用 `accepted_window_indices`，不复制成功样本。
`conditions[].windows` 只含本次成功的完整窗口。原样本原有 valid 状态另存为
`valid_before_window_rejection`；窗口拒绝后所有样本 valid/accepted 为 false。
全部调节、PM 读数和无效读数仍附在 power 证据及事件日志中。

每次重试先停止激励、确认清理并关光，再重新开光、完整调光／判稳和电学核对。
暗点不重测，严格保留同一 baseline_key / dark_condition_id 和暗态时间。
追加次数由整个亮功率 visit 共享，总时间也不随重试或内层坐标重置。
超出次数／总预算抛 `PowerRecoveryExhausted`，结束并清理整轮，不跳过失败点。
无信号、硬功率／reduce-above 超限、执行器不可达、仪器保护、通信不明、
审计失败或清理失败都立即停止，不走普通光学重试，也不增加输出寻找信号。

默认 JSON/SQLite 分析及 unified plotting 只取整轮完成且清理确认后的有效窗口。
audit 视图将失败尝试作为独立观察，显示 power_attempt 和 power_retry_reason，
不计入成功窗口均值。Monitor 显示粗／细调、等待稳定、电学核对、正式采集、
重试原因／次数／清理，以及目标、实测值、相对偏差、电流设定和稳定失败原因。

Unified plotting 已有 `actual.optical_power_w` 横轴，复用其适配器，继续保留
`requested.optical_target_power_w`。本轮补充 PM100D 测量位置标签和
“not sample-calibrated”标注；该值不是未经校准就可称为样品处功率。

## 通信与耗时

已完成的去重保留：正常单电学坐标三次读取用 7 轮完整 23-query 核对，
不是原来的 15 轮；首次配置可能额外核对一次。只共享这次 READ 对应的证据，
不跨样本缓存；实际设置改变、重新连接、错误、调光恢复后均重新核对。
源、保护、光学和读数前后状态检查不移除。同总线／串口仍串行。

串口默认继续使用实机已验证的 100 ms。20/40/80/100 ms 退避代码只作为显式
注入的离线试验，未加入运行配置，也未自动切换。现有单调剩余等待继续复用，
不叠加通信期间已经耗费的 settle。

下游查询 1,106→554，时钟 111.01→55.81 s。含新增采集前 PM 屏障。

原始 timings 保留各阶段及 audit 的单调时钟；父阶段包含子阶段，不能重复
