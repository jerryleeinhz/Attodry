## 1. 设置和检查属于哪个边界

开发前分别列出首次连接、轴入口、真正改变设置、正式采样及清理的通信清单。
同一字段的 requested、readback 和分析值分别保存，不能用旧状态证明现在安全。

- 所有模块先完成只读 preflight，之后才进入有授权的配置阶段。NKT 模式不同
  默认拒绝；只有显式 `allow_control_mode_change=true` 才在健康且确认 OFF 时切换。
- read-before-write，相同设置不重复写。实际变化后读回核验并通知受影响的探测器。
  不引入正常采样中的宽量程/临时 Reserve 过渡来制造额外等待。
- PM `read_sample()` 负责这一次新鲜 READ 前后完整设置/状态核验；外层复用该
  样本的 `before`、`after`、sequence 和时间，不另做相同 PM capture。
  激光、调制器、SMU、环境及电学保护继续独立检查。
- 证据复用只属于同一次采样边界，没有跨样本有效期、全局“已检查”开关或用
  FETCh 替代新 READ。READ 内设置漂移、传感器更换和未知状态仍拒绝。
- 相同 PEM 波长/延迟设置可以执行已有状态核验，避免再次激活或写 AMP。
  设置变化和核验失败不得沿用旧稳定证明。斩波器在固定光学组内保持运行；
  其启动、参考和锁定核验独立于 XY 是否锁定。

实测 fake 命令预算只统计 PM 或 PEM 本身，**不包含其他仪器通信**：

| 边界 | 旧实现 | 当前实现 | 保留的证据 |
|---|---:|---:|---|
| PM 设置已匹配的单次 prepare | 26 | 13 | 一次完整新鲜 capture；连续两次 prepare 各 13 |
| 一次正式 PM 采样边界 | 66 | 27 | READ 前 13＋新鲜 READ 1＋READ 后 13 |
| 同波长/延迟 PEM 再准备 | 15 次通信 | 5 次查询，无设置写入 | 现有身份/设置/稳定/频率核验 |

PM 真正写设置后仍重新完整 capture。预算来自相同 fake 生产路径；它们不是
真实点周期或百分比提速，也不证明光功率/样品/机械斩波器的暂态已稳定。
这里的 27 次是单次功率 READ 的边界。一个完整 Combination 电学采样窗通常有
before/formal/after 三次功率 READ，即至少 81 次 PM 交易；等待守护或其他阶段
可能另有采样，不能把整组测量或所有仪器的总通信数理解为 27。

## 2. 轴入口与判稳证明

温度、磁场在本次轴点进入时完成完整判稳，随后执行内层测量；内层仍读取实际
温场和质量/保护状态。根据轴索引与 visit scope 区分相同数值的重复访问。
回访、重复扫描、新尝试与未来恢复不得继承前次判稳；硬件断点恢复仍按现有入口
能力限制。磁场执行器内部的安全中间点、到场、稳定等待和最终实际回零保留。

本分支光电 profile 的目标、命令和接受读回都满足
`sqrt(Bx^2 + Bz^2) <= 3 T`。不能从参考分支或历史单轴策略移入更宽边界。
通信失败不代表场为零；SMU OFF/source register 零也不代表电容实际已放空。

光学在外层时，同一光谱/目标功率组先调光判稳，再保持照光完成内层 gate/锁相。
固定设置不反复开关光或重启斩波器。启用匹配暗背景时，每个需要新暗态的条件
显式关光采集，属于必要测量成本，不能借连续照光配置隐藏或复用不匹配暗态。

## 3. 剩余等待与串行通信

每路锁相以单调时钟计算最后一次相关变化之后的剩余时间：

```text
required[role] = time_constant_s[role] * settle_time_constants
remaining = max(0, max(last_change[role] + required[role]) - now)
```

XX/XY 共同等待，随后依次读取。只有最后一次实际变化之后的工作耗时可以抵扣。
光学最终调节、gate 设置完成、环境判稳和参考/谐波/量程变化分别通知其影响。
真正调档后重新计时；无变化的重复 qualify 只补剩余时间并读取新鲜保护证据。
正式入口也补足所需等待，不能跳过 qualify 而提前接受读数。

内部 XX 光学准备先核实源与设置，不在开光前支付一整段探测器滤波等待，也不把
XY 尚在追锁时的频率观察值当成合格参考。XY 在照光后的资格与正式入口仍执行
原有严格频差和能力检查；斩波器单独核验 XX 基频及自身准备状态。

`dwell_s` 表示完整照光保持时间时仍完整执行；功率稳定窗口、hold、采样间隔、
仪器积分和滤波等待各自有独立含义。不能为了速度静默缩短窗口、TC 或配置倍数。
等待期间保留光学/源/环境守卫和共享期限，不能替换成无保护的裸 sleep。

共享 GPIB/串口按应答归属串行访问，不开并行 monitor 消费 LIAS 或交叉读响应。
空响应、迟到响应、半包和 I/O 错误保留原始数据并使不确定会话失败；不能靠清
总线、reset 或无限重发提高通过率。参考分支的短串口轮询试验不作为新默认值。

## 4. 调光速度、稳定性和完整窗口恢复

原 `point / per_target / previous / grid` 起始策略保留，维度、量化和物理限值
仍离线校验。局部响应模型只在同光谱/执行器上下文使用；改变光谱、状态未知、
失败或清理后清空。NKT 电流局部斜率只有正向实测证据才参与缩步，不把电流比
当作光功率比。反向减半和最大单步边界保留，接近目标时进一步细调。

`tuning_tolerance_fraction` 是显式初始调节精度，不得宽于正式目标容差；省略
保留旧行为。相对峰峰值、绝对噪声底和漂移趋势均显式配置，省略保留原绝对窗口。
相对峰峰值上限为 `min(max_peak_to_peak_w, max(noise_floor_w, target*fraction))`。
这些是质量条件，不能静默放宽来获得更好计时数字。

正式窗口冻结执行器，记录目标和实测功率。`record_continue` 只允许原定的普通
目标偏差继续，不扩展到硬功率/电流限制、失明搜索、身份/设置异常或通信未知。
`max_power_retries=0` 保持默认不恢复。显式有限重试重复完整 before/所有模块/
after 候选，不拼接不同候选的 XX、XY、SMU 或功率读数。

恢复的一个共享单调期限覆盖重调、等待、重新核验以及最终正式 READ。期限外的
最后读数只能保留为失败证据，不得 promotion。普通偏差与 hard after-bracket
故障混合时按 hard fault 停止，不用主错误类型遮住后续状态不明。
审计/清理失败不能自动再开光。所有旧失败窗口、部分读回及清理错误保留。
