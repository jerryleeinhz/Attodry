## 完整目标与分支边界

- NKT 扫波长／光功率，CLD 控制固定波长二极管的光功率；PM100D 实测 W 用于反馈。源电流和百分比只是调节量，不是实际光功率。
- 当前 DC photoresponse 组合线支持选用无激励、6221 DC、2182A 电压、2400／Three-SMU，以及温磁场组合。只连接选中的模块，防止重复设备所有权和双激励源冲突。
- 早期 `integration-photonics-nonlinear-hall` 是 PEM／锁相集成线，涉及 SR830/SR865A、谐波、参考链路、光学与 gate 组合。不能把该分支的接线、record_continue政策或配置字段直接移入当前 `module/integration-photovoltage/current` 活动路径（原名 `module/NKT-photonics`）。
- 当前仓库代码与临时实机入口是不同交付物：本次纯 CLD/PM 测试入口和机器配置保存在 ignored `run_data`，没有成为受版本控制的通用 CLI。

## 测量经验

- 明确区分目标、执行器设置、实际读回及有效样本。PM测量面不自动等于样品面；电流设定不等于实测电流。
- 光学稳定后保持照光，再遍历同一光学条件下的gate，可减少重复调功时间。跨光学组的清理／重新稳定必须按当前实现执行。
- 按波长和功率提供合适初始电流、误差大时用有界大步长、接近目标或反向时缩步，可减少反馈时间。不能为追功率越过器件电流上限。
- settle与time constant只能处理部分瞬态／噪声，不能修复失锁、过载或错误参考。继续记录的异常仍需保留质量标志，默认分析排除无效样本。
- 空图先查质量剔除、谐波是否实际采集、条件分组和缺失值。闭环的起始源百分比不应自动当作必须分组的独立物理条件。
- 命令成功、输出OFF、设定零和实际读回零是不同证据。通信失败后不能推断磁场／栅压归零。始终保持合成磁场不超过3 T。
- 正常中断后核验清理，不强杀采集；失败原始数据保留，新尝试用新run ID。

## 当前六点测试约定

| 参数 | 已确认／已准备值 |
|---|---|
| 控制器 | CLD1010LP；不能像NKT设置波长和10 nm带宽 |
| 二极管标称波长 | 用户确认730 nm；旧约760 nm文字不再适用于本次测试 |
| 目标功率 | 0.05、0.64、1.23、1.82、2.41、3.00 mW |
| 光路 | 用户最后确认只照PM100D，冷台样品被遮挡；新操作前核对是否变化 |
| LD电流 | 批准上限30 mA，准备入口初始10 mA |
| TEC | 26°C，批准电流上限0.85 A |
| 测试功率上限 | 3.3 mW软件测试限值，不是探头额定值 |

准备入口复用 `CldController` 与 `PhotoresponsePower`，不创建冷台、锁相、SMU或其他电学资源。不要直接用可能构造电学设备的完整入口替代它。

已准备资格窗口：目标±5%，2 s窗口、至少3个新鲜样本、0.3 s间隔、峰峰值≤5 µW、hold0.5 s，每点1200 s超时；最大电流步长0.6 mA，反向缩步。资格通过后冻结调节量，采10个正式新鲜读数，间隔1 s。低／负功率或不足1 nW时停止，不自动加电流找光。

验收需全六点及最终LD OFF、设定电流0、实际电流≤10 µA、原TEC开关状态恢复、资源close及审计通过。到30 mA仍达不到目标，应记录不可达。

已报告测试：入口fake 12/12、CLD VISA 31/31、功率26/26；目标机118文件manifest离线验证通过。默认TEMP权限曾造成文件测试失败，使用工作区可写临时目录后通过。以上不代表实机反馈成功。

## CLD诊断矛盾与下一步

最近只读快照是在LD OFF、TEC ON且约26°C时取得：LD与TEC的 `CONN:TRIP?` 为1，`STAT:MEAS:COND?` 为8192（bit13）。安装座可识别为A/D/E/G，极性AG；已查钥匙、interlock、过温等未显示触发。未发出清状态、重置、刷固件或LD开启命令。

用户随后报告手动能出光。这是现场证据，尚无同一时刻的软件诊断。下一步应在确认当前光路及设备所有权后，比较手动正常出光和关闭后的相同只读诊断、实际电流／电压，必要时同步PM读数。不能默认此刻还在出光。

如果正常出光时仍置位，需要核实固件／状态语义；如果仅关闭时置位，需要针对状态设计解释和测试。任一种结果都不是无条件忽略所有保护的依据。不要重复询问已确认的控制器型号。

厂家资料：

- [CLD101x User Guide，DOC-104674，Rev B，2026-05-18](https://media.thorlabs.com/globalassets/items/c/cl/cld/cld1015/doc-104674.pdf?v=0527024711)
- [编程手册 DOC-104772，Rev B，2026-05-27](https://media.thorlabs.com/globalassets/items/c/cl/cld/cld1015/doc-104772.pdf?v=0527060057)
- [官方软件页](https://www.thorlabs.com/en/software-pages/4000_series)

手册仍将CONN定义为连接故障保护，将bit13定义为插座缺失／未知插座；不是USB连接状态。错误弹窗约7秒后消失，“现在无ERROR”不能单独解释这些状态。

CLD1010LP安装检查应按A/D/E/G引脚、STYLE跳线和转接板连接固定进行，不能套用CLD1015的蝶形封装Type1/2。没有查到连接故障专用复位命令。`*CLS`清事件与错误队列，`*RST`恢复默认；温度保护Reset Delay不是插座故障复位。重启不是已证实的必需恢复方法。

官方TL4000原生初始化即使reset=false仍发送清状态／preset命令，getter可能消费错误队列；不能当作纯只读复核。当前使用VISA query-only。厂家询问草稿仅保存在本地，未发送、未收到厂家答复。
