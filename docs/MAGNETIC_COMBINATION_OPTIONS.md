# 磁场组合扫描：判稳、质量偏差与安全边界

2026-10-22 操作者批准本次软件修改、提交和 LK_setup 文件部署。
本次实施范围包括磁场质量策略、命令上下文限值、配置及文档；速度优化方案未获批准。
小步转场、每个中间点/起点/终点的判稳、读取顺序/次数、ACK、锁相核验、背景、滤波等待及清理流程保持原有调度。

## 配置位置与可选值

```toml
[combination_scan]
order = ["magnetic", "optical", "lockin"]
magnetic_deviation_policy = "record_continue"
```

| 字段 | 合法值 | 省略时 | 作用阶段 |
|---|---|---|---|
| `[combination_scan].magnetic_deviation_policy` | `"abort"`, `"record_continue"` | `"abort"` | 本次磁场点完整判稳通过后的内层采集 |
| `[magnet].readback_tolerance_t` | 严格 loader 校验的正数，至多 0.0015 T | 依既有配置契约 | 入点与采样目标容差；单轴非工作轴硬残余边界独立保留 |
| `[magnet].stable_range_t` | 严格 loader 校验的正数 | 依既有配置契约 | 判稳窗口/正式采样窗口的峰峰差 |
| `[magnet].stable_dwell_s` | 严格 loader 校验的正数 | 依既有配置契约 | 入场完整连续稳定窗口 |

`magnetic_deviation_policy` 放在组合扫描表，是因为它决定外层已判稳之后如何处理内层测量质量。
它不是磁体硬件限值，也不属于初始判稳参数。独立 magnetic-field 命令不使用此选项。
未选择 magnetic 轴时，非默认 `record_continue` 拒绝加载，避免无效配置造成误解。

## 运行行为

每次进入新磁场点都必须经过完整写入/ACK、实际到场及连续判稳。
同值的重复访问、回访、重复扫描也保留原来的入场流程；既往资格不能代替本次资格。

| 事件 | `abort` | `record_continue` |
|---|---|---|
| 初始到场/连续判稳超时 | 停止并清理 | 停止并清理 |
| 判稳后实际场偏离目标容差 | 保存原始证据并停止 | 保存偏差和警告并继续 |
| 正式采样窗口场峰峰差超过质量阈值 | 保存原始证据并停止 | 保存范围和警告并继续 |
| 关闭磁场控制、外部改变目标、设备错误 | 停止并清理 | 停止并清理 |
| 通信失败、非有限值、未知状态、硬边界超限 | 停止并清理 | 停止并清理 |
| 非工作轴残余场超过硬边界 | 停止并清理 | 停止并清理 |

继续采集不是重新判稳，不修改目标，不自动补偿或重试，不承诺暗/亮态磁场相等。
正常结束选 `hold` 且目标非零时，同一策略允许目标误差作为警告保留，清理验证只说明控制/目标保持，
不认证稳定。`zero` 清理和零目标 hold 均必须实际回零通过，不能用质量策略豁免。
样本保留实际 Bx/Bz、目标、采集时间、资格来源、目标误差、窗口范围与质量警告。
组合分析提供 `magnetic_quality.*` 字段供显式筛选；accepted 表示通过当前继续策略，不能据此宣称磁场仍稳定。
同步读回是采样边界证据，不是连续时间全程监测。

## 单轴与双轴硬边界

新加载的硬件磁场组合策略按**当前命令及转场上下文**决定边界，归档版本为
`command-scoped-readback-v1`（具体字段见预览快照）。旧记录保留自己的版本，不重新解释。

| 当前设场 | 硬边界 |
|---|---|
| X 非零、Z 目标严格为零 | X 的配置标称上限；实际 Z 另受残余边界保护 |
| Z 非零、X 目标严格为零 | Z 的配置标称上限；实际 X 另受残余边界保护 |
| X、Z 同时非零 | 两个轴各自的配置上限，且合场不超过配置 `experiment_vector_max_t`（至多 3 T） |

配置限值不能高于已确认设备额定值；本台既有确认上限为 X 3 T、Z 9 T，
但较低的具体 TOML 上限仍然有效。本次 −3..+3..−3 T 接管配置保留 X/Z 各 3 T，
不会因为支持更高单 Z 场而自动扩大扫描。新策略不增加旧式 0.5 mT 硬边界余量。
命令严格零包括 signed zero；不能用实际读回接近零来切换模式或绕开保护。

完整点列先后用 X 和 Z，不再单凭“整轮用过两个轴”限制所有单轴端点。
精确 float32 目标、每个安全小步、逐轴写入的混合拐角，以及最新实际场与将写命令的组合仍要检查。
从高 Z 场转到 X 场时必须确认前一轴已经降下；设定值 ACK 不代表实际场已降下。
危险的 direct 路径拒绝；不会自动改成 `via_zero`，后者会改变磁滞历史，必须由配置明确选择。
回零过程中保持前一非零命令的轴上下文，直到实际回零确认；不会把仍在衰减的单 Z 场误判成双轴或已零场。

实际到零需要原有读回容差和稳定窗口；通信失败保留最后确认值与未知状态，需要人工核验。
故障清理逐项独立尝试；若最新完整状态的硬场越界等故障使动作前核验失败，
回零或温控关闭仍可能未获确认。保留各动作的失败、最后读回及 manual-review 标志，不能宣称已安全关闭。
温度/无磁场轴的环境保护和独立磁场入口保留各自版本契约。
